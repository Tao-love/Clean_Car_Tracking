# 1-3 已批准实施基线摘要

本工程的唯一架构基线是 2026-07-20 已批准的 `1-3：MSPM0G3507 循迹小车无线自动整定批准方案`。本摘要便于 GitHub 仓库独立阅读；详细字节布局以 [protocol.md](../protocol.md) 为准，必要实施细化以 [deviations.md](../deviations.md) 为准。

## 硬件和限制

- MSPM0G3507、两只 MG310 AB 编码器电机、TB6612FNG、八路数字灰度、JDY-31 SPP、XDS110。
- PA8/TX1→JDY-31 RXD，PA9/RX1←JDY-31 TXD，共地，JDY-31 使用稳定 5 V；首联 9600 baud。
- TB6612 STBY 固定 5 V，不可由 MCU 控制。统一停车必须同时清零两路 PWM 和四个方向脚。
- 首版不采购或连接电池 ADC、电流检测、摄像头、Wi-Fi；PA25 实际用于灰度 D6。
- XDS110 只用于烧录/调试，正常无线试验不需要连接。

## 职责

- MCU：100 Hz 控制、左右速度 PI、八路循线 PD、500 tick 试验、本地安全、统计、显式 Flash 保存。
- Python：独占蓝牙 COM、心跳、可靠命令、候选生成、试验编排、评分、last-safe 回滚、日志、VOFA+ 转发。
- VOFA+：只观察 Python 本机转发，不打开蓝牙 COM，不参与评分；未运行不影响自动整定。

## 安全和状态机

状态为 `BOOT_SAFE / IDLE / ARMED / RUNNING / FINISHED / FAULT / FLASH_WRITE`。

- 心跳每 100 ms；RUNNING 连续 400 ms 无合法帧时本地停车。
- 八路全未触发持续 150 ms 时本地停车（仅循线模式）。
- 高 PWM、低编码器速度持续 300 ms 时本地停车并区分左右轮。
- 每次 trial 最多 500 个 10 ms tick，第 500 tick 本地停车。
- RUNNING 中参数锁定；pending 只在非 RUNNING 的 10 ms 边界整组切为 active 并递增版本。
- 首次电机试验车轮悬空，首次落地 PWM 不高于 25%；电池插头必须能立即拔除。

## 控制、统计和寻优

- 增益统一有符号 Q16.16；左右轮允许独立 PI/前馈，具有限幅、积分限幅和条件积分抗饱和。
- 循线误差权重为 `[-3500,-2500,-1500,-500,500,1500,2500,3500]`；外环为带差分低通和尖峰限幅的 PD。
- MCU 本地累计 IAE、平方和、最大/P95 误差、丢线、速度、PWM、饱和、符号翻转、编码器和超期；实时遥测丢失不改变最终汇总。
- Python 正常评分综合 MAE、RMSE、P95、丢线、饱和、振荡和速度；任何安全故障施加不能被速度奖励抵消的失败惩罚。
- 阶段顺序：悬空电机辨识→悬空速度 PI→低速循线 PD→逐级速度爬升。首版使用有边界网格/坐标搜索。

## Flash 和注释

- 每个候选只改 RAM；只有 IDLE 中明确 `COMMIT_PARAMS` 才写 Flash。
- 双槽记录包含 magic、schema、generation、length、paramVersion、参数和 CRC；新槽读回有效后才采用，坏槽回退旧槽或保守默认值。
- 人工维护代码使用清楚的中文模块/函数/DriverLib 说明；AI 新增 C/Python 块分别用 `// ----- AI` / `# ----- AI`。TI 官方启动文件和 SysConfig 生成文件不手工插标记。

## 仍需实物输入

轮径、编码器每轮实际计数、启动 PWM、左右差异、堵转阈值、线宽、闭环长度、直角位置、起始姿态、允许速度、重复 trial 次数和直角策略必须在基础链路通过后标定，不在软件中伪造。
