# Clean_Car 无线运行 PWM 上限提高到 1000

## 目标

允许手动上位机通过完整 `SETALL` 快照写入 `PWM:1000`，以便在本次上电期间测试比 600 更高的电机输出上限。

## 范围

- 将 `src/control_params.c` 中通用运行参数校验的 `PARAM_PWM_MAX` 从 600 提高到 1000。
- 将 `src/UART_Auto_PID.c` 中无线 `SETALL` 校验的 `UART_AUTO_PID_PWM_MAX` 从 600 提高到 1000。
- 默认参数 `maxPwm=600` 保持不变；不会自动提升已烧录的默认输出。
- 电机驱动的硬件限幅 `MOTOR_PWM_PERIOD=1600` 保持不变。
- 上位机不改动：它不在本机拦截 600，固件 ACK 才是当前拒绝来源。

## 运行行为

`PWM:1..1000` 的完整 `SETALL` 将可接受并仅写入 RAM；`PWM:1001` 仍被拒绝。复位或重新上电后，参数仍回到编译期默认值 600。

## 验证

- 固件主机测试应覆盖 `PWM:1000` 成功应用和 `PWM:1001` 被拒绝。
- 重新编译 CCS 工程，确认修改的 C 源可构建。
- 不执行烧录、通电或车辆运行；实车测试由用户在确认 ACK 后手动进行。
