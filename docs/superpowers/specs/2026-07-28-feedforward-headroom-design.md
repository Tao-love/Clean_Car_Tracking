# Clean_Car 前馈留余量设计

## 目标

修正当前 `baseSpeed=27`、`maxPwm=300` 下，左右固定前馈已单独超过 PWM 上限的问题。用户明确要求不新增“饱和且零速时自动暂停”逻辑。

## 决策

- 固定前馈由左 `42`、右 `34.5` 改为左 `7`、右 `6`。
- 保持 `baseSpeed=27`、左右速度 `Kp=12`、`Ki=0` 与 `maxPwm=300` 不变。
- 不提高 PWM 上限；固件硬上限继续是 400。
- 另行在上位机展示已有的左右独立目标、速度与 PWM 字段；本设计不改变控制或停车状态机。

## 理由与验收

新前馈单独输出为左 `7*27=189`、右 `6*27=162`，分别留出 `111`、`138` 的 PWM 修正空间。应先悬空烧录测试：稳态不应由前馈本身顶住 300；独立遥测将用于判定两路编码器是否一正一负。启动瞬间在实际速度为 0 时，P 项仍可短暂限幅，此情况不作为前馈饱和。
